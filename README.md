# show-info

정보시스템 설계 과제물 _ 김수

고척스카이돔 공연 관람객을 위한 통합 정보 서비스 MVP입니다. 「정보시스템 설계와 평가」 기말 팀 프로젝트의 와이어프레임(Figma)을 실제로 눌러 볼 수 있는 웹앱으로 옮겼습니다. 1단계 대상은 고척스카이돔이고, 이후 다른 공연장으로 확장하는 구조입니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| 홈 | 맨 위 이번 달 공연 슬라이드 배너(옆으로 넘기기, 오늘 이후 첫 공연부터), 공연장 선택, 내 티켓 카드, 오늘 할 일, 맨 아래 공식 안내 게시판(분류별, 원문 링크) |
| 시야 | 좌석 구조도에서 구역 선택 → 그 자리 눈높이의 3D 예상 시야, 실제 사진과 후기, 티켓 인증 관람객의 시야 등록 |
| 공연장 | 3D 시설 구조(층별 보기, 출입문, 매점, 아기쉼터, 엘리베이터), 입장, 시설, 상권, 주차. 항목을 누르면 지도로 이동 |
| 이동 | 지도 블록 + 지하철, 버스, 주차 목록. 목록을 누르면 지도가 그 위치로 이동 |
| 이동 (내 위치) | 위치를 허용하면 목록을 가까운 순으로 보여 주고, 고른 곳까지 앱 안에서 도보(Tmap), 대중교통(ODsay) 경로선과 단계 안내. 자동차는 네이버 지도 앱으로. 위치는 저장하지 않음 |
| 마이페이지 | 탭 화면 오른쪽 위 사람 아이콘. 내 정보, 내 티켓, 내가 올린 시야, 위치 사용과 귀가 알림 설정 |
| 커뮤니티 | 시야 후기, 동행 안전 수칙, 공연 정보 |

## 실행

빌드가 필요 없는 정적 페이지입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 배포 (GitHub Pages)

1. 저장소 Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
2. 1~2분 뒤 `https://snowater121.github.io/show-info/` 에서 열립니다.

## 네이버 지도 설정

1. 네이버 클라우드 콘솔 → Maps → Application → 사용할 앱 → 변경
2. API 선택에서 **Dynamic Map** 체크 (주소를 좌표로 바꾸는 Geocoding은 앱에서 쓰지 않고 `tools/geocode_places.py`로 한 번만 실행해 좌표를 적어 둡니다. 키는 `.env`에만, 커밋 금지)
3. 웹 서비스 URL에 아래 주소 추가
   - `https://snowater121.github.io`
   - `http://localhost:8000` (내 컴퓨터에서 확인할 때)
4. `config.js`의 `NAVER_CLIENT_ID`에 Client ID 입력 (이미 입력됨)
5. 지도 자리에 "인증 실패" 안내가 뜨면 `config.js`의 `NAVER_KEY_PARAM`을 `'ncpKeyId'` ↔ `'ncpClientId'`로 바꿔 보세요.

네이버 지도를 불러오지 못하면 실제 좌표로 그린 약도가 대신 나옵니다.

### 키 관리 주의

- **Client Secret은 저장소에 절대 올리지 마세요.** 이 저장소는 공개 저장소라 누구나 볼 수 있습니다.
- Client ID는 브라우저에 노출되는 값이라 공개되어도 괜찮지만, 등록한 웹 서비스 URL에서만 동작합니다.
- 길찾기(Directions)처럼 Secret이 필요한 API는 서버(예: Vercel 서버 함수)에서만 호출해야 합니다.
- 앱 안 경로 안내는 브라우저에서 바로 부르는 키를 씁니다. `config.js`의 `TMAP_APP_KEY`(TMAP API 보행자 경로), `ODSAY_API_KEY`(ODsay LAB 대중교통, 웹 URI에 `https://snowater121.github.io`, `http://localhost:8000` 등록). 공개되는 값이라 Tmap은 콘솔에서 사용량 한도를 걸어 두세요.
- 무료 이용량은 대표 계정에만 있으니, 콘솔에서 일별·월별 이용 한도를 설정해 두세요.

## 데모 한계

- 3D 모형은 공식 도면이 아닌 실측 치수 기반의 단순화 모형입니다. 무대 위치와 구역 배치는 공연마다 다릅니다.
- 가입, 티켓 인증, 시야 등록은 브라우저 저장소(localStorage)에만 저장되고 다른 사람과 공유되지 않습니다. AI 검수는 흉내만 냅니다.

## 주변 상가 데이터 갱신

상가정보는 분기마다 새로 올라옵니다. 원본 CSV(시도별 수백 MB)는 저장소에 올리지 않고, 필요한 부분만 `data/shops.json`으로 뽑아 씁니다.

1. 공공데이터포털에서 「소상공인시장진흥공단_상가(상권)정보」 zip을 받아 압축을 풉니다.
2. 수도권 파일 세 개를 넘겨 실행합니다.

```bash
python3 tools/build_shops.py --base 2026-09-30 경로/*_서울_*.csv 경로/*_인천_*.csv 경로/*_경기_*.csv
```

3. 공연장을 늘릴 때는 `tools/build_shops.py`의 `VENUES`에 확인한 좌표를 추가하고 다시 실행합니다.
